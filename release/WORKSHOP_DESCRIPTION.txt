[h1]Better Vehicle Dynamics[/h1]
A drivetrain and traction overhaul for Project Zomboid Build 42. Every vehicle gains a torque-curve driven engine, surface- and weather-aware grip, and a stack of optional realism systems - all sandbox-tunable, all multiplayer-safe.

[h2]New: ZombieBuddy support (recommended)[/h2]
BVD now runs through [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url]. [b]This is now the recommended way to play BVD:[/b] no zombie folder to copy, nothing to redo when Project Zomboid updates, and no clashes with other mods over replaced game files. The manual install still works if you prefer it. Dedicated servers need no Java install either way.

[h1]What it changes[/h1]
[list]
[*][b]Torque-curve acceleration[/b] - engines pull from a real power curve instead of a flat number. Low-end grunt for shoving wrecks, a proper top end.
[*][b]Surface & weather grip[/b] - independent traction on sealed road, rain, snow and off-road. Lose the back end if you push it.
[*][b]Tyre-type grip model[/b] - worn / standard / modern tyres each get distinct grip per surface, not one flat value.
[*][b]Load affects handling[/b] - a heavily loaded vehicle is slow to pull away from a stop, as if the engine is straining against the weight. Strength is a sandbox slider.
[*][b]Load affects fuel[/b] - hauling heavy burns extra fuel while driving.
[*][b]Configurable drag[/b] - air drag and rolling resistance (road and off-road) are separate, tunable knobs.
[*][b]Reference power & weight[/b] (opt-in) - researched HP/mass figures for the vanilla fleet; modded vehicles can register their own, and modded cars without an entry get the same power boost.
[*][b]Cargo-capacity rescale[/b] - per-body-type storage multipliers instead of one blanket override.
[*][b]Drift mode[/b] (opt-in) - hold a bindable key to break the rear loose for an arcade slide. Off by default.
[*][b]Tyre marks[/b] - vehicles leave a ground decal when a tyre breaks loose; marks fade out on their own.
[*][b]Vehicle info panel[/b] - a docked readout beside the mechanics window showing the active profile, per-surface grip, tyre type and cargo load.
[*][b]Ground-clip guard[/b] - a safety net that snaps a vehicle back onto its floor if it ever sinks into the ground (a multiplayer desync class). Only ever acts on an impossible state, so normal driving, ramps and basements are unaffected.
[/list]

[h1]Tuning[/h1]
Everything is exposed in Sandbox Options, grouped into [b]Handling[/b], [b]Tyres & Load[/b], [b]Drivetrain[/b] and [b]Readout & Misc[/b] pages, plus quick tuning presets. Defaults aim for a grounded, readable feel; dial it toward arcade or hardcore to taste.

[h1]Multiplayer[/h1]
Built for dedicated servers and co-op. Load-sensitive fuel is server-authoritative so it behaves consistently for everyone.

[h2]Installation (players)[/h2]
Better Vehicle Dynamics has two parts: this Workshop subscription (Lua, sandbox options, UI) and a Java part (the deep physics - engine code a Lua mod cannot reach). [b]The subscription alone is not enough[/b]. Pick [b]one[/b] way to get the Java part. [b]Option A is recommended.[/b]

[b]Option A - ZombieBuddy (recommended, no file copying).[/b] If you use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url], just enable it together with this mod. BVD's Java loads through it automatically: nothing to copy, and no recopying after Project Zomboid updates (BVD itself updates through the Workshop as usual). ZombieBuddy asks you to approve BVD's Java the first time.

[b]Option B - manual install (only if you don't use ZombieBuddy).[/b]
[olist]
[*]Subscribe to this mod and let Steam finish downloading it.
[*]Open the mod folder: [code]Steam\steamapps\workshop\content\108600\3728775267\mods\BetterVehicleDynamics\B42.21_Manual_Install\[/code]
[*]Copy the [b]zombie[/b] sub-folder from there into your Project Zomboid install directory (right-click Project Zomboid in Steam -> Manage -> Browse local files).
[*]Restart Project Zomboid.
[/olist]
When Project Zomboid itself updates, recopy the [b]zombie[/b] folder to refresh it.

Use one option, not both. If both are present the manual install wins and the ZombieBuddy part stays off. To switch from B to A, run Steam's [i]Verify integrity of game files[/i] to remove the copied classes.

[h2]Dedicated server hosts[/h2]
[b]The server needs only the Workshop mod - no Java install.[/b] A dedicated server never simulates vehicle physics; each driver's own game does. So hosted servers without a [code]java/zombie[/code] folder (most rented-server panels) are fine: add the mod to the server's Workshop and mod lists as usual. Every [i]player[/i] sets up the Java part (option A or B above) on their own PC.

Already copied the zombie folder onto a server under the old instructions? It is harmless, and you can delete it.

[h2]Updating from 0.1.15 or older[/h2]
[b]Easiest:[/b] switch to ZombieBuddy (option A). Run Steam's [i]Verify integrity of game files[/i] to remove the old copied classes, enable ZombieBuddy, done.

Staying on the manual install? Copy the new [b]zombie[/b] folder over the old one as usual, then [b]delete these two files[/b] from your Project Zomboid folder. Copying over the old folder does not remove them, and they are no longer part of the mod:
[list]
[*][code]zombie\iso\IsoChunkMap.class[/code]
[*][code]zombie\iso\sprite\IsoSprite.class[/code] (plus the two [code]IsoSprite$...class[/code] files next to it)
[/list]
Or run Steam's [i]Verify integrity of game files[/i] and then copy the new zombie folder.

[h1]For modders[/h1]
A public Lua API lets other mods register vehicle reference data, tyre-grip profiles and content packs without touching this mod's files. Full reference: [url=https://branched-almanac-460.notion.site/Better-Vehicle-Dynamics-Public-Lua-API-36542ef13d238106a7afda59a82181f6]Better Vehicle Dynamics - Public Lua API[/url]

[h1]Compatibility[/h1]
Works alongside vehicle-skin and content mods. Run only one vehicle-physics overhaul at a time. Build 42.21+.

[b]Maskarad's Summer Car:[/b] works from v0.1.17 (earlier versions crashed with it). Its engine adds about 150 kg to a car, which BVD's load penalty counts as cargo, so those cars launch a little slower than they would without it. Deeper integration (following its manual or automatic gearbox) is planned, not done.

Other manual-install Java mods (for example the PZ Optimization / tuner kind) clash only if they ship the same class files. BVD now ships only [code]CarController[/code], [code]WorldSimulation[/code], [code]Texture[/code] and [code]IsoFloorBloodSplat[/code] (it no longer touches [code]IsoChunkMap[/code] or [code]IsoSprite[/code]). If another Java mod ships one of those four, only one of the two mods' copies can be active. With ZombieBuddy (option A), BVD replaces no game files at all, so this kind of clash goes away.
