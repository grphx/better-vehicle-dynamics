## What the first pass found and how it was fixed

- A reviewer read the v0.2 controller changes and found that the idle governor raises the vehicle's throttle
  value before the stall and engine-braking checks read it, so a stall at a standstill in 1st/2nd/reverse and
  engine braking from idle could not trigger. The checks now read a separate driver-throttle value that the
  governor never touches. (The first fix, reading the vehicle throttle earlier, was not enough: that value still
  carries last tick's governor bump. Caught by the 1st-gear stall check.)
- Smaller review fixes: a stale stall request after leaving the seat, split-screen players overwriting the
  clutch state, shift-point shares above 1 from a modded engine profile, repeated stall requests.
- Test bugs, not mod bugs: `clutch` braked to a stop with the clutch out, which stalls a manual car (correct
  behaviour) - the test now presses the clutch to stop; `profiles` required two upshifts in 9 s - now one per run;
  the multiplayer restart after a stall needed a short wait for the engine to finish shutting down.
- `msc` failed once with "car moves 0.0 km/h" and passed 9/9 on the rerun. This is the known stuck-spawn quirk of
  the harness (a debug-spawned car sometimes never moves, also without BVD).
- The plain `sp` test car reached only 28 km/h in one run (46 in others); the KI5 CarNormal road figures are the
  same as 0.1.19/0.1.20, so this is test variance.

## Not tested

- The manual-install path (compiled classes) was rebuilt from the same source but not installed into the game.
- Gamepad input, split-screen, and the "lock-up on a gear far too low" option in a real downshift.
- Translations were machine-drafted and only checked for valid JSON and the same keys as English; they were
  not read in game.
- Clear-grass speeds of 17-31 km/h at 5 s are the same as in 0.1.19/0.1.20 (a known property of the off-road
  model, see issue #1), not something 0.2 changed.

batch rerun on the final build:

With the option on, the window power is now the script value (plain car 4000, Beetle 4560; it was 16000 and 18240)

the change, which only applies with the realism option on).
