[h1]Better Vehicle Dynamics[/h1]
A drivetrain and traction overhaul for Project Zomboid Build 42. Every vehicle gains a torque-curve driven engine, surface- and weather-aware grip, and a stack of optional realism systems - all sandbox-tunable, all multiplayer-safe.

[h2]Needs ZombieBuddy[/h2]
BVD's deep physics run through [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] (a free Workshop mod): subscribe to it and enable it together with BVD. Since Project Zomboid 42.22 this is the only way: the game's jar is now signed and refuses the old manual install (copying a zombie folder), so that option is gone. Dedicated servers need no Java and no ZombieBuddy.

[h1]What it changes[/h1]
[list]
[*][b]Torque-curve acceleration[/b] - engines pull from a real power curve instead of a flat number. Low-end grunt for shoving wrecks, a proper top end.
[*][b]Surface & weather grip[/b] - independent traction on sealed road, rain, snow and off-road. Lose the back end if you push it.
[*][b]Tyre-type grip model[/b] - worn / standard / modern tyres each get distinct grip per surface, not one flat value.
[*][b]Load affects handling[/b] - a heavily loaded vehicle is slow to pull away from a stop, as if the engine is straining against the weight. Strength is a sandbox slider.
[*][b]Load affects fuel[/b] - hauling heavy burns extra fuel while driving.
[*][b]Engine braking[/b] - lift off in gear and the engine slows the car; the revs follow road speed, so a downshift raises them. Strength slider, never more than half the tyre grip.
[*][b]Manual clutch, neutral and stalling[/b] (opt-in) - hold the clutch key (Left Ctrl) to disengage, find neutral between reverse and first, and stall if you let the clutch out in too high a gear without throttle.
[*][b]On-screen stick shift[/b] - an H-pattern gate on the HUD: amber with the clutch in, red when you stall.
[*][b]Engine-type shift points[/b] (opt-in) - the automatic shifts like the engine type: vans early, sports cars late.
[*][b]Acceleration ceiling[/b] - caps how hard any car can launch, whatever its engine, tires or grip slider.
[*][b]Configurable drag[/b] - air drag and rolling resistance (road and off-road) are separate, tunable knobs.
[*][b]Reference power & weight[/b] (opt-in) - researched HP/mass figures for the vanilla fleet; modded vehicles can register their own, and modded cars without an entry get the same power boost.
[*][b]Cargo-capacity rescale[/b] - per-body-type storage multipliers instead of one blanket override.
[*][b]Drift mode[/b] (opt-in) - hold a bindable key to break the rear loose for an arcade slide. Off by default.
[*][b]Tyre marks[/b] - vehicles leave a ground decal when a tyre breaks loose; marks fade out on their own.
[*][b]Vehicle info panel[/b] - a docked readout beside the mechanics window: active profile, per-surface grip, tyre type, cargo load and which Java part is running.
[*][b]Ground-clip guard[/b] - a safety net that snaps a vehicle back onto its floor if it ever sinks into the ground (a multiplayer desync class). Only ever acts on an impossible state, so normal driving, ramps and basements are unaffected.
[/list]

[h1]Tuning[/h1]
Everything is exposed in Sandbox Options, grouped into [b]Handling[/b], [b]Tyres & Load[/b], [b]Drivetrain[/b] and [b]Readout & Misc[/b] pages, plus quick tuning presets. Defaults aim for a grounded, readable feel; dial it toward arcade or hardcore to taste.

[h1]Multiplayer[/h1]
Built for dedicated servers and co-op. Load-sensitive fuel is server-authoritative so it behaves consistently for everyone.

[h2]Installation (players)[/h2]
Better Vehicle Dynamics has two parts: this Workshop subscription (Lua, sandbox options, UI) and a Java part (the deep physics - engine code a Lua mod cannot reach). [b]The subscription alone is not enough[/b]: the Java part loads through ZombieBuddy.
[olist]
[*]Subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3619862853]ZombieBuddy[/url] and to this mod.
[*]Enable both in the Mods list.
[*]Start the game and approve BVD's Java when ZombieBuddy asks the first time.
[/olist]
Nothing to copy and nothing to redo when Project Zomboid updates (BVD itself updates through the Workshop as usual). Without it BVD tells you with a short notice at the top right of the screen, and driving stays vanilla.

[b]Used the old manual install?[/b] Run Steam's [i]Verify integrity of game files[/i] to remove the copied zombie folder (on 42.22 the game will not start with it), then follow the steps above.

[h2]Dedicated server hosts[/h2]
[b]The server needs only the Workshop mod - no Java install.[/b] A dedicated server never simulates vehicle physics; each driver's own game does. So hosted servers without a [code]java/zombie[/code] folder (most rented-server panels) are fine: add the mod to the server's Workshop and mod lists as usual. Every [i]player[/i] sets up the Java part (ZombieBuddy, above) on their own PC.

A zombie folder already copied onto a server is harmless; you can delete it.

[h1]For modders[/h1]
A public Lua API lets other mods register vehicle reference data, tyre-grip profiles and content packs without touching this mod's files. Full reference: [url=https://branched-almanac-460.notion.site/Better-Vehicle-Dynamics-Public-Lua-API-36542ef13d238106a7afda59a82181f6]Better Vehicle Dynamics - Public Lua API[/url]

[h1]Compatibility[/h1]
Works alongside vehicle-skin and content mods. Run only one vehicle-physics overhaul at a time. Build 42.21+ (42.22 verified).

The mechanics-window info panel also works with CleanUI and Clean UI 2.0 (Rax's Reborn).

[b]Maskarad's Summer Car:[/b] works from v0.1.17 (earlier versions crashed with it). Its engine adds about 150 kg, which BVD's load penalty counts as cargo, so those cars launch a little slower.

With ZombieBuddy, BVD replaces no game files at all, so it does not clash with other Java mods.
